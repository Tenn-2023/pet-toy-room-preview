# 微信小游戏适配与上传说明

更新日期：2026-11-15。此包为原生 Canvas 2D 微信小游戏，不是打开网页的 WebView。主线60关、无尽、能量、道具和本机存档继续共用原规则，不需要业务后端、账号登录或排行榜服务。

## 这次改了什么

| 项目 | 之前 | 现在 |
| --- | --- | --- |
| 构建 | 网页与微信一起生成 | 增加独立微信构建、正式上传构建，网页可分别发布 |
| AppID／广告位 | 改源码，重建后要重填项目配置 | 使用构建目录之外的 config/wechat.local.json，重复构建保留配置 |
| 模拟广告 | 微信未填广告位时也出现模拟领奖按钮 | 微信默认禁用广告；未接广告返回原有“广告暂时不可用”反馈，不发奖。模拟广告只能在开发配置显式开启，正式构建拒绝模拟 |
| 广告完成判断 | 已有完成判断 | 保留严格 isEnded===true 才领奖，补充加载异常、并发请求、晚到回调和监听清理的验证 |
| 启动 | 串行等待全部玩具素材分包 | 只等待首关必要的网球包；其他玩具、头像、视频、通关动画按需加载，下载复用且失败重试 |
| 首页视频 | 启动时阻塞加载视频包 | 封面放主包先显示，视频异步加载；不支持解码时仍可开始游戏 |
| 运行内存 | 启动即请求全部玩具图片 | 玩具图片首次展示时才创建并缓存；音效复用，切后台暂停 |
| 屏幕 | 只按窗口尺寸等比缩放 | 微信安全区内等比布局，避开刘海、右上胶囊、底部手势条，点击坐标同步换算；窗口信息不再每帧查询 |
| 包体 | 没有整体包体报告，旧构建可能残留 | 每次清理生成目录和 Mac 元数据，统计主包／12个分包，超项目预算即构建失败 |
| 构建检查 | 游客 AppID 也能产出同一目录 | 导入测试包允许游客；正式构建要求真实 AppID，并开启 URL 检查 |

当前资源无需 CDN。主包约2.28 MiB，总包约18.48 MiB；构建后精确数据见 artifacts/wechat-upload-adaptation/import-package-report.json。当前最大分包约3.08 MiB。项目采用保守预算：主包4 MiB、每个分包4 MiB、总包24 MiB；这是项目的构建门槛，最终可上传范围与后台要求以微信开发者工具及当前账号校验为准。

## 配置一次，之后不用改源码

复制 config/wechat.example.json 为 config/wechat.local.json，并填写：

```json
{
  "appId": "填写真实小游戏 AppID",
  "projectName": "pet-toy-room",
  "rewardedVideoAdUnitId": "",
  "simulateAds": false
}
```

- AppID 格式是 wx 开头加16位十六进制字符。请使用“小游戏”的 AppID。
- 没有接入激励广告时广告位留空；主线和无尽仍可玩，视频奖励暂不可用。已有广告位时填写 adunit-…。
- 不需要、也不要在项目中填写 AppSecret。该配置文件已被 .gitignore 排除；构建文件不包含 AppSecret。
- 仅本地调试模拟广告时才可把 simulateAds 改为 true，且广告位留空；上传前必须恢复 false。浏览器试玩继续保留模拟广告，不受微信配置影响。
- 存档使用微信本地存储。不会与浏览器存档同步，清除小游戏数据或换设备后无法从服务器恢复。

## 导入与正式构建

仅生成微信导入测试包：

```sh
npm run build:wechat
```

在微信开发者工具中导入 /Volumes/Tenn_BLACK/IAA/dist/wechat/，选择小游戏。未填写 AppID 时这是游客导入包，不能据此声称已经可提交审核。

填写真实 AppID 后生成正式构建：

```sh
npm run build:wechat:release
```

正式目录是 /Volumes/Tenn_BLACK/IAA/dist/wechat-release/。如果 AppID 缺失、格式错误或仍开启模拟广告，命令会明确报错并停止，不产生新的正式包。每次构建分别重建其输出目录，原始配置、源图和存档不会被清理。包体报告放在 artifacts 中，不计入上传包。

导入正式目录后，通过开发者工具完成预览、真机调试、上传，后台再提交体验／审核／发布。游戏名称、图标、介绍、类目、隐私声明、备案／资质及运营信息应按当前账号后台显示的要求补齐；这里没有替账号填写或提交，也没有承诺已通过审核。

## 已验证与仍需真机验证

自动化验证覆盖：60关原有通关路径、无尽实时最高分／撤销保留纪录／道具耗尽失败卡、微信安全区坐标、分包并发去重和失败重试、广告取消／异常／重复／晚到回调、正式包配置拦截；微信模拟宿主还检查所有素材路径、首次启动按需加载、视频循环、后台释放与恢复、空触摸事件。

微信开发者工具已安装，当前未提供真实 AppID 或广告位，尚未进行微信真机测试或正式上传。请在开发者工具及 iOS／Android 真机确认：

1. 首次安装与弱网加载、断网后恢复。
2. 刘海屏、带底部手势条的手机以及平板：顶部按钮、待放盒和底部按钮都可见、可点。
3. 首页视频、通关动画和图鉴大图的内存与流畅度；切后台后视频、声音暂停，返回后棋盘与最高分保留。
4. 配置真实广告后，完整播放才领奖，提前关闭／无填充／网络失败不领奖；同局各道具次数限制保持。
5. 退出重进、重开、撤销后，本机最高分不下降，旧主线进度正常续玩。

接口实现对照微信官方 [小游戏 API 类型定义](https://github.com/wechat-miniprogram/minigame-api-typings)，包含 getWindowInfo、getMenuButtonBoundingClientRect、loadSubpackage、RewardedVideoAd。正式提交前请以开发者工具与账号后台的实际检查为准。
