# 宠物托管屋 · 手机试玩

独立的浏览器试玩发布仓库，与“小狗店长的面包屋”分开维护。

[打开手机试玩](https://tenn-2023.github.io/pet-toy-room-preview/)

30关宠物玩具整理小游戏，完成前15关后解锁高难度无尽模式；包含视频循环客厅、玩具图鉴、能量、障碍和从第6关开始的关卡内爪爪币。图鉴仅显示“已解锁／未解锁”，交付任务栏隐藏动物品种文字，只保留头像；每页6款，奖励以数字＋爪爪币图标显示。激励视频目前明确标记为模拟广告。

普通关卡达到本关所有整理目标即通关，通关前持续随机补充收纳盒，不要求供给耗尽或棋盘清空。每组六件，第1／10／20／30关分别需要4／14／26／40组。每关开局无预放玩具，三个可选盒及下一盒预览从底部出现，支持拖拽或点击摆放。

“关卡挑战／无尽模式”选项卡支持重玩任何已解锁关卡。无尽模式没有通关目标，栏位全满失败，或由玩家主动结束；每交付六件同款得100分，保存本机最高分。每局随机2处杂物，没有锁栏或爪爪币。排行榜界面可分页查看完整前100名，目前未接入线上服务，明确显示未开放；后端部署包已在源项目准备。开始或重试消耗1能量，续玩同一局不再次扣除。

归并只在放下新收纳盒时判定：以新盒为中心，先比较四周旧盒的匹配同款数量，更多的先处理；一盒多款相同取最高单款数量，同量按上→右→下→左，每侧一次。旧盒交付、撤走或腾出空间不会启动其他旧盒归并。全局先减少分散、凑满六件、形成单款盒并保留已有单款集中成果，不限定原位置。同等分盒结果先保留新盒原有款式继续与未处理邻盒合并的机会，再少量移向多量；同量保留原单款盒中的款式，两边都单款或都混装则归旧盒，不按栏位编号决定。非同款仅为凑满六件或让两盒都单款而让位，不能只为未凑满的同款挤出其他玩具。两盒都满可同时交换，容量不超过六件。旧盒2鼠＋2花生旁放新盒2鼠，会得到旧盒2花生、新盒4鼠。旧盒2飞盘旁放新盒3飞盘＋1球，得到旧盒1球、新盒5飞盘，不能仅为保留旧盒原款让3个反向移向2个。

上方1鼠、左侧4鼠、下方2飞盘，中间放入2鼠＋2飞盘时，左侧凑满6鼠交付，上方1鼠不动，下方变4飞盘，中间撤走。

首关开始一次性显示用户确认的全部七条合并规则，点击“已了解”继续；右上角❓与底部规则入口反复打开同一内容。前两步用网球和白绳结教学，随后骨头咬胶加入同一关卡。

供给更丰富：前五关最多两款混装，第6关起加入三款，第12关起加入四款；空间拥挤时限制复杂混装。第6关开局已有小鱼混装盒，收尾也不会连续只发小鱼纯盒。合并规则版本12、奖励规则版本2、挑战栏位版本2；旧版本未完成的一局免费重新整理，不再扣能量。

挑战关卡交替安排纯混装、杂物与锁栏：第1、2、3、5、7、10、13、16、20、23、26关没有杂物和锁栏。总棋盘12格固定，每关锁栏最多3格。萨摩耶任务头像已修正为白色成犬，与比格分别对应。

“刷新待放列表”保留视频图标，观看前验证候选并显示下一步收益，撤销每局一次免费，之后最多3次成功的视频撤销，连续两次退两步；空位紧张时提示这两个救场入口。广告仍是模拟，实际广告观看率和留存待试玩验证。

普通第6关起，每项奖励任务交付1组即得爪爪币，无需等整项完成；每项每局一次，不重复领奖。锁栏费用按关卡阶段为8／12／16币，奖励总额为全部锁栏费用＋4币；无锁栏关卡不发币。任务清单明确标出“1组奖励4”等节点（所有奖励门槛均为1组），附黄色透明底爪印图标。重开重新赚币和解锁，无尽模式只计分。能量每30分钟恢复1点，离线有效。

锁栏按关卡难度安排，不固定在底部：前期放角落，中期使用侧边，后期部分锁栏影响中间的邻接路线。每关最多3格，关闭全部锁栏时仍保留连通的可用区域；每关两条免费路径验证不依赖开锁。第6关锁右上角、第17关锁第二行中间，第30关锁右上及第二行中、右侧。重开位置不变，仍须重新花币解锁。

每关在保存的验证种子下有两条不同的免费通关路径；运行时重开会改变后续随机供给，不保证所有随机种子或中间状态都可解。撤销恢复随机数状态，再做同一步不会重抽后续盒。

规则或栏位配置更新后，旧版本未完成的一局免费从当前关卡重新开始，保留能量、已解锁关卡和图鉴。手机竖屏打开网址即可试玩；存档属于当前浏览器，不跨设备同步。
