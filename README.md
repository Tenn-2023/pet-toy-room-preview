# 宠物托管屋 · 手机试玩

独立的浏览器试玩发布仓库，与“小狗店长的面包屋”分开维护。

[打开手机试玩](https://tenn-2023.github.io/pet-toy-room-preview/)

30关宠物玩具整理小游戏，通关第30关后解锁高难度无尽模式；包含持续动画客厅、玩具图鉴、能量、障碍和从第6关开始的关卡内爪爪币。图鉴仅显示“已解锁／未解锁”，交付任务栏使用“泰迪”名称。激励视频目前明确标记为模拟广告。

普通关卡达到本关所有整理目标即通关，通关前持续随机补充收纳盒，不要求供给耗尽或棋盘清空。每组六件，第1／10／20／30关分别需要4／14／26／40组。每关开局无预放玩具，三个可选盒及下一盒预览从底部出现，支持拖拽或点击摆放。

“关卡挑战／无尽模式”选项卡支持重玩任何已解锁关卡。无尽模式没有通关目标，栏位全满失败，或由玩家主动结束；保存本地最高交付组数。开始或重试消耗1能量，续玩同一局不再次扣除。

归并只在放下新收纳盒时判定：以新盒为中心，按上→右→下→左检查四邻，每侧一次。旧盒交付、撤走或腾出空间不会启动其他旧盒归并。优先将新盒同款分流到相邻旧盒，不按数量或栏位编号决定方向。两盒有同款时可交换其他玩具让位；两盒各2鼠＋1飞盘会留下旧盒4鼠、新盒2飞盘。两盒都满仍可同时交换，始终不超过六件容量。

首关开始一次性显示用户确认的全部七条合并规则，点击“已了解”继续；右上角❓与底部规则入口反复打开同一内容。前两步用网球和白绳结教学，随后骨头咬胶加入同一关卡。

供给更丰富：前五关最多两款混装，第6关起加入三款，第12关起加入四款；空间拥挤时限制复杂混装。第6关开局已有小鱼混装盒，收尾也不会连续只发小鱼纯盒。合并规则版本7允许单款匹配时通过交换其他玩具让位，旧版本未完成的一局免费重新整理，不再扣能量。

视频换盒显示已验证的下一步收益，撤销每局一次免费，之后可看视频；空位紧张时提示这两个救场入口。广告仍是模拟，实际广告观看率和留存待试玩验证。

每关在保存的验证种子下有两条不同的免费通关路径；运行时重开会改变后续随机供给，不保证所有随机种子或中间状态都可解。撤销恢复随机数状态，再做同一步不会重抽后续盒。

规则更新后，旧版本未完成的一局免费从当前关卡重新开始，保留能量、已解锁关卡和图鉴。手机竖屏打开网址即可试玩；存档属于当前浏览器，不跨设备同步。
