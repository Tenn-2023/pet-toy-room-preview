# 宠物托管屋 · 手机试玩

独立的浏览器试玩发布仓库，与“小狗店长的面包屋”分开维护。

[打开手机试玩](https://tenn-2023.github.io/pet-toy-room-preview/)

30关宠物玩具整理小游戏：持续动画客厅、玩具图鉴、能量、障碍、从第6关开始的关卡内爪爪币及锁定栏位。激励视频目前为明确标记的模拟广告。

手机竖屏打开试玩网址即可游戏，支持拖拽和点击摆放。进度保存在当前浏览器；换设备、换浏览器或清除网站数据后不共享进度。

归并只在放下新托盘时判定：以新盘为中心，按上→右→下→左检查四邻同款。旧盘不会因其他盘交付或撤走再次自动归并。游戏待放区下方可点击“规则”查看完整说明。

每关棋盘均不预放玩具，全部来自底部待放托盘；首关也可自选托盘与空位。整理量逐关增加，第1／10／20／30关分别为4／14／26／40组，每组六件。混装供给和同款分散程度同步增加；30关均有不依赖广告或购买的通关解法。

开局和整理量更新后，旧版本未完成的一局会免费从当前关卡重新开始，保留能量、关卡进度和图鉴。

本仓库只包含浏览器运行文件。GitHub Pages 的发布来源为 `main` 分支根目录（`/`）；`.nojekyll` 保留静态资源原样发布。

更新时，在原始项目目录运行 `npm run build:pages`，再提交、推送本目录的生成文件。不要上传原始美术、开发备份、微信包、账号凭证或本地存档。
