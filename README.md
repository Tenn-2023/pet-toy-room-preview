# 谁把玩具弄乱啦？ · 手机试玩

[打开手机试玩](https://tenn-2023.github.io/pet-toy-room-preview/)

30关竖屏宠物玩具整理小游戏，支持点击或拖动待放收纳盒进入棋盘空位。每盒容量六件，同款集齐六件自动交付；达到本关全部任务即可通关。完成挑战前15关后解锁计分无尽模式，排行榜后端暂未接入公网。存档保存在当前浏览器，激励视频仍为模拟广告。

新收纳盒放下时，与四周旧盒逐一整理；先比较放置瞬间同款数量，更多的邻盒先处理，同量按上、右、下、左，每侧一次。两盒能分成两个不同款的单款盒时优先分别归盒，再按原数量规则决定归属；不能分开时少量向多量合并，同量整款优先归旧盒，旧盒放不下时归新盒。只有同一款时仍正常合并、凑满六件交付，不强行保留两个盒子。新盒原有款式全部移出后，本次后续方向不再从其他旧盒抽回。旧盒交付或腾位不会触发其他旧盒继续合并，换位爪另行触发。合并版本16、奖励版本3、挑战布局版本3；进行中的旧版本局免费从当前关重开，能量及已解锁进度保留。

首页右上角为玩具图鉴，不显示道具数量；关卡选择上移到无尽排行榜下方。游戏及通关提示的返回按钮统一为“回到首页”。

首次进入游戏界面会显示4页“玩具整理小手册”，须逐页阅读后在最后一页点击“进入游戏”，可以返回前页查看。图解依次说明数量不同、同量时的旧盒空间、多个邻盒的顺序及超过六件时的交付保留；第1、3、4页带逐件跳动搬运，方向及落点对应实际整理结果。交付位置先播放白色星光，再在空位显示“交付成功”，第3、4页支持重播。说明不修改正在玩的棋盘、任务或能量，完成阅读后继续实操教学，完成记录保存在当前浏览器。

游戏不显示完整文字规则，通过首次出现时的高亮提示引导放置、交付、杂物、锁栏与道具操作。首关依次放2、3、1件网球完成交付，再引导4件白球、2白球＋1骨头的混装盒和5件骨头，直到两款都交付一次；支持点击、拖动、跳过及中途续玩。前五关最多两款混装，第6关起少量三款，第16关起少量四款。每关最多3个锁栏，位置按难度安排；有锁栏的关卡爪爪币总奖励为解锁费用加8，部分任务交付1组即可领取，币仅本回合有效。

道具栏最多同时拥有6个道具，库存可跨关保留，每种道具每回合只能使用一次；未拆随机礼盒不计上限，满栏的关卡赠送道具保存为待领取奖励。炸弹可选择一至两处杂物或未完成盒清理，换位爪交换两个已放盒并触发整理，小火箭可选一条横排或竖列清理；锁栏仍需爪爪币。三种道具均可完整观看模拟视频获取，图标为原创手绘Canvas绘制。

第5、10、15关首次通关分别赠送换位爪、炸弹、小火箭；第20关首次进入赠送换位爪与炸弹，第25关首次进入赠送全部道具各1个，均不重复。第8、18、28关首次通关赠送随机道具小礼盒，直接进入道具栏；点击后放大、抖动、开盖并随机获得1个道具。

每回合免费撤销1次，随后最多3次成功的视频撤销，连续观看可回退多步；取消或失败不占次数。按钮固定显示“撤销”与同色手绘视频符号，用完额度后变灰。换盒按钮显示“刷新待放盒列表”与同色视频符号，观看前验证候选组合，成功刷新后不能撤销此前摆放。

能量初始10点、上限20点，每15分钟自然恢复1点，离线有效；开始或重试消耗1点，首次通关返2点、重复通关返1点。恢复倒计时位于能量数值下方。通关统一显示“整理好啦”，六只宠物动画按六关一轮显示，相邻关不重复。

客厅使用地毯修复版布偶猫视频：1.15倍速预处理、静音循环、704×1472、25fps，视频约1MB且索引前置。进入关卡或切到后台暂停，返回首页续播，不持久缓存视频帧。

合并动画逐件从实际原格子移向接收盒的实际落点，移动时不保留原位重复影像；轻微侧弧跟随移动方向，不再统一向上弹。

本仓库只包含浏览器运行文件，独立于“小狗店长的面包屋”。GitHub Pages来源为main分支根目录，保留.nojekyll。更新时在源项目运行npm run build:pages，再提交并推送生成文件；不上传原始美术、开发备份、微信包、账号凭证或本地存档。

首关操作提示统一为“选这个盒子，放到红色框内”，首次小字“点击或拖动都可以”保留；提示框贴近当前盒子或目标空位，以红色流动虚线箭头连接对应红框。教学放置后同款轻微发光，玩具按真实方向飞行且不绘制移动方向箭头，多邻盒时优先处理的盒子描边并配短提示；普通操作及跳过教学后的自由操作不出现这些效果，也不增加教学等待。网球交付后继续引导白球盒、白球加骨头的混装盒和骨头盒；每步配简短小字，混装实操单独记录完成状态，旧文字提示或网球后重开不会漏掉。交付提示自动继续，不再显示长段排序说明。泰迪通关动画保持0.9倍速。

首关教学结束时提示“还有一个小委托未完成哦！”，高亮剩余任务卡并用上下摆动的手绘箭头指向它，短暂展示后自动继续，可自由完成剩余一组骨头咬胶任务。提醒沿用混装教学的完成记录，不反复出现，也不改变任务目标或合并规则。
